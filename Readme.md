# Xqmac8: Custom INT8 Instructions for EfficientNet-Lite0 on RV64IMC

Bare-metal INT8 inference of **EfficientNet-Lite0** on an **RV64IMC** core (target: CV-Wally), simulated on **Spike**.
Two custom instructions are added to accelerate quantized convolution:

| Instruction | Function |
|---|---|
| `qmac8 rd, rs1, rs2` | `rd = sext32( int32(rd) + Σ(i=0..7) int8(rs1.byte[i]) × int8(rs2.byte[i]) )` — 8 INT8 MACs per instruction |
| `qrequant rd, rs1, rs2` | TFLite-compatible requantization (multiply, rounding shift, add zero point, clamp) of one int32 accumulator in a single instruction |

Three configurations are compared:

| Config | Build | 1×1 convolution |
|---|---|---|
| **B0** | `make spike` | plain C loop + software requant |
| **X1** | `make spike XQMAC=1` | `qmac8` + software requant |
| **X2** | `make spike XQMAC=2` | `qmac8` + `qrequant` |

To make the work much easier to understand and learn, I only modified the 1x1 convolution part. The rest is still using software to calculate.

## 1. Custom Spike build-up

```bash
git clone https://github.com/riscv-software-src/riscv-isa-sim.git
cd riscv-isa-sim
git checkout 17e8a69fb75546dea445cfc0fb78769d2510f339
git apply https://github.com/Miso9029/aca_midterm/spike/spike_xqmac.patch

mkdir build && cd build
../configure --prefix=$RISCV
make -j$(nproc)
make install
```
It clone the required spike source code and make sure the user use the same environment as mine.
The patch adds `riscv/insns/qmac8.h`, `riscv/insns/qrequant.h`, and registers both instructions in
`riscv/encoding.h`, `riscv/riscv.mk.in` and `disasm/disasm.cc`.

## 2. Run the test

All commands below are run in `src/nn/`.

### Short test for custom instruction 

```bash
make test-xqmac
```
This will test whether the spike modification is correct

Expected output:

```
== Xqmac8 verification ==
qmac8    : 20028 tests, 0 failed
qrequant : 50166 tests, 0 failed
RESULT: ALL PASS
```

### Full model

```bash
make spike            # B0
make spike XQMAC=1    # X1
make spike XQMAC=2    # X2
```
This will print out per layer: retired instruction, total cycles, MACs per instruction, and OK/FAIL check of the output against the golden data.
It should end with:
```
top-1 = 208 (golden 208)
layer failures = 0
RESULT: PASS
```
which means the model correctly get the right picture: Labrador Retriever in data/

## Instruction mix 

```bash
spike -g --isa=rv64imc build_x2/model.elf > x2_run_g.txt 2>&1
python3 ../../scripts/mix_report.py build_x2/model.elf x2_run_g.txt ../../results/x2
```
It gives the information that the actual RISC-V code usage distribution.
In `..._mix.txt` it shows the actual function usage.
In `..._mix_class.txt` it categorize into alu / load / branch / mul / store / custom.
